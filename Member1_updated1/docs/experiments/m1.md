## 2026-11-18 FastText + SVM

- SBERT cache was not present in the Member1 package, so the first executable SVM used the team's scratch-trained FastText mean vectors.
- FastText was trained separately for each outer fold using only that fold's training IDs; the `full` version used only the development set for test inference.
- Linear SVM (`C=0.1, 1, 10`) best pooled OOF Macro-F1: **0.5080** (`C=0.1`).
- RBF SVM (`C=0.1, 1, 10`; `gamma=scale, 0.01, 0.1`) best pooled OOF Macro-F1: **0.5278**, Accuracy **0.5344** (`C=1, gamma=scale`).
- All configurations, run IDs and parameters are recorded in `results/m1_svm.csv`; prediction shapes are 1,222 OOF rows and 303 test rows per run. Test labels were not used.
- This is a valid FastText-SVM experiment, but it is not the planned SBERT-SVM comparison. Re-run with the verified SBERT cache when it becomes available.

## 2026-11-21 SBERT + SVM

- Received member 5's frozen `sbert_multi` vectors (paraphrase-multilingual-mpnet-base-v2, revision 4328cf2, 1525 x 768, L2-normalised); SHA-256 of both files matches `M5_SBERT_sentence_vectors/manifest.json`, and IDs match clean_v2 exactly. Copied to `data/emb/`.
- `member1/svm.py` now takes `--embedding {fasttext_mean,sbert_multi}` and `--class-weight {none,balanced}`. Frozen SBERT uses one shared matrix for all folds and the test set; the StandardScaler is still fitted on training folds only.
- Linear SVM, C in {0.0001, 0.0003, 0.001, 0.003, 0.01, 0.1, 1} x class_weight {none, balanced}: best pooled OOF Macro-F1 **0.5748** (C=0.001, none). Smaller C is better, i.e. strong regularisation.
- RBF SVM, C in {0.3, 1, 3, 10, 30} x gamma {scale, 0.0003, 0.003} x class_weight {none, balanced}: best pooled OOF Macro-F1 **0.5985**, Accuracy **0.6015** (C=3, gamma=scale, balanced; run `svm__sbert_multi__20261121-145728-06de`). Per-class F1: Neutral 0.593 / Positive 0.624 / Negative 0.579. Results plateau at 0.594-0.599 for C >= 3 with gamma=scale, so the choice is not a single lucky point.
- Versus the official baseline (Macro-F1 0.5820): +0.0165. Versus FastText-SVM (0.5278): +0.0707, so the embedding matters more than the kernel.
- Caveat: hyper-parameters were chosen on the same five folds that report the score (41 SBERT configs), so 0.5985 is slightly optimistic; no nested CV was run.
- Run environment: scikit-learn 1.9.1 / Python 3.13 (cloud workspace), not the team-pinned baseline environment. Test predictions saved for every run; test labels not used.
