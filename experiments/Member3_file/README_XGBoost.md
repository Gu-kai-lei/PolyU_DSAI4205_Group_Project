## Training and integration

- Open [22_m3_xgboost.ipynb](../../notebooks/03_models/22_m3_xgboost.ipynb) for executable code and model evidence. Set `RUN_TRAINING = True` to reproduce. Members 1 and 4 can reuse the code cells and read training results from `m3_xgboost.csv`.
- Run `python experiments/Member3_file/m3_xgboost.py` from the team repository in the `dsai4205` environment. It writes the shared scoring ledger using `save_result`, and writes the OOF and test probability file using `save_preds`. Existing team `sbert_multi` arrays are reused. The script can regenerate the embeddings if the cache is absent. For the exact ONNX runtime path used here, add `--onnx-dir` pointing to the pinned `model.onnx` and `tokenizer.json` and install `onnxruntime==1.20.1` and `tokenizers==0.20.3` in the local environment.
- Use `clean_v2`, `folds_v1` and seed 42. The official development/test counts are 1,222 and 303. The recommended encoding + descriptor run is **`xgboost__sbert_multi__20261121-143943-a632`**, pooled OOF Macro-F1 **0.5789**. An independent script rerun creates a new run ID. Use that new ID to load its regenerated predictions.
- Team probabilities are stored outside Git under `DATA_ROOT/preds/`. The file has `oof_ids`, `oof_proba`, `test_ids`, `test_proba` and class order `[0, 1, 2]`. Test probabilities are for Member 1’s project-level evaluation. The notebook reports only official development OOF metrics.

## Output files

| File in `Member3_file/` | Use |
|---|---|
| `m3_xgboost.csv` | Shared evaluator metrics for both configurations |
| `m3_inner_search.csv` and `m3_fold_metrics.csv` | Inner search, chosen early-stop rounds and five outer-fold scores |
| `m3_per_class.csv` and `m3_oof_confusion.png` | Precision, recall, support and mistakes on development OOF |
| `m3_shap_global.png` and `m3_shap_descriptors.csv` | Named descriptor impact across held-out folds |
| `m3_summary.json` | Provenance, hashes, versions and run IDs |

Copies of `m3_xgboost.csv`, `m3_shap_global.png` and `m3_oof_confusion.png` are also in the root `results/` and `figures/` folders. The private prediction cache is regenerated by training or copied separately to shared `DATA_ROOT/preds/`.

Reruns write evidence to a new directory under `local_artifacts/xgboost/` unless `--output` is supplied. The original handoff keeps its published run IDs.
