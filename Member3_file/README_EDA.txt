Integration
Extract this package at the repository root. It adds Member3_file/EDA/ without changing other members' files.
Do not upload this ZIP as the only deliverable; upload its extracted files so members can browse them on GitHub.
No input data are duplicated: code automatically locates the team's existing data/raw and data/clean_v2 folders in ancestor directories.
Run from Member3_file/EDA using the team dsai4205 environment: python eda_analysis.py.
Alternatively open 00_eda.ipynb and Restart Kernel and Run All.
Figure numbering is local to the EDA contribution and should be reconciled when merging the final report.
