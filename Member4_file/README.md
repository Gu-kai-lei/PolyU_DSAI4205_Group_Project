## 可以放

- notebook（`.ipynb`）和代码（`.py`）
- 报告章节草稿、PPT 页、实验记录
- 图片（`.png`）和结果表（`.csv`）

## 不要放

- 数据缓存、嵌入向量和模型权重（`.npy`、`.npz`、`.pt`、`.pth` 等），这些文件太大
- 密钥、密码和账号信息（例如 `.env`）
