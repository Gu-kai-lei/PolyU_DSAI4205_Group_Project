# 课程资料、日志和报告草稿

这里保存课程资料和小组开发记录。

- [materials/](materials/)：项目说明、最终报告模板和数据集说明，阅读原文确认要求。
- [meetings/](meetings/)：会议记录，复制 `_template.md` 后按日期命名。
- [experiments/](experiments/)：个人实验记录，记录参数、结果和改进过程。
- [cleaning_log.md](cleaning_log.md)：清洗规则、影响数量和前后示例，由 `01_cleaning` 自动生成。
- [report_drafts/](report_drafts/)：报告各节的英文草稿，按组员编号命名，例如 `m2_cleaning.md`。

每位组员记录自己负责的工作。提交用报告的语言和格式按课程要求处理。
