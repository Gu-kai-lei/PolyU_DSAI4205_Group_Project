### C.3 Iterations

Each change below was made because a check showed a problem. The full records are in `data/clean_v2/clean_v2_log.md` and `docs/experiments/`.

| Date | Change | Reason and evidence |
|---|---|---|
| 26 Oct | Hashtags are no longer split into words (`clean_v1` → `clean_v2`) | VADER agrees with the labels on 91.9% of retained tweets when hashtags stay whole, 88.1% when they are split on capital letters and 71.1% when *stockmarketcrash* is split. Splitting adds words such as *crash* that VADER would not score in the raw text. |
| 26 Oct | Lost characters are removed and flagged (`emoji_lost`) instead of replaced by a placeholder token | Transformer models would read the placeholder as a word. |
| 26 Oct | Non-English tweets and tweets without words set aside for the current experiments | 73% of the non-English tweets and all tweets without words are labelled Neutral, and an English lexicon cannot check these labels; the rows stay in `clean_v2_all.csv` for a later comparison run. |
| 26 Oct | Second language check added (stopwords of other languages) | A check of the retained tweets found 16 French, Spanish, Italian and Romanian tweets that the first rule had kept, because the English word lists we used (NLTK words and WordNet) also recognise words such as *de*, *la* and *en*. The retained data went from 1,541 to 1,525 tweets. |
| 26 Oct | FastText models made smaller and reproducible | With gensim's default of two million hash buckets each model took about 800 MB; we use 200,000 buckets and a fixed hash function so that every run gives the same vectors. |
| 26 Oct | Task division revised (version 2) | The report and slides were split so that each member writes and presents their own part; other tasks were moved to even out the workload. |
| 27 Oct | Repository tidied | Member 1's files had been uploaded as a copy folder through the GitHub web page; they were moved to their standard places and a rule was added to use branches and pull requests. |
| 27 Oct | Test split no longer scored during development | The test split is scored only once, after the experiment freeze, so that it cannot influence model choices. |
| 27 Oct | Two label-noise filters tested for kNN and rejected | Removing tweets flagged by confident learning (0.461) or the VADER disagreements (0.456) both lowered the CV macro-F1 from 0.473. |
| 2 Nov | EDA, official baseline run and interim report | Done by member 2 so that the interim report could be assembled on time; members 1, 3 and 4 review their parts. |
| 3 Nov | Report wording revised after an internal review | Label origin is described as highly consistent with VADER rather than proven; removed tweets are described as set aside for the current experiments; limitations added. |
