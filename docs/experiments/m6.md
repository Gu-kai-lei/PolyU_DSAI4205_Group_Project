## Notes

- Both comparisons use `folds_v1` and `clean_v2`. FastText is trained per fold: fold k never sees that fold's text, and the test text is used only by the `full` vectors.
- Imbalance choice uses out-of-fold macro-F1. A gap under 0.005 would have kept the simpler method. `class_weight` clears that gap. Recommendation for the other models: `class_weight="balanced"`, or inverse-frequency weights on a neural-net loss. Do not oversample before the split.
- These absolute scores stay below the TF-IDF baseline (CV macro-F1 0.582). FastText on 1,525 tweets is a weak embedding; kNN on the same vectors was 0.473. The imbalance table is about the treatment, not about beating the baseline.
- The submitted BiLSTM is the 2-layer network. Early stopping uses a 15% group holdout inside the training folds, so the reported fold does not pick the epoch. The test run uses the median of those epochs (10) and is scored once.
- On the test set the 2-layer model still misses most Negative tweets: 26 correct, 54 called Positive. The error heatmap for id 1610 puts its weight on *hike*, *rate* and *interest* and almost ignores *recession* and *bearmarket*.
- Focal loss was not run. Member 5's frozen token sequences are not in the repo yet. The network already takes `(batch, length, dim)` plus a mask, so those sequences can replace FastText without a structural change.
